> *"Sem dados, você é apenas mais uma pessoa com uma opinião sem provas."*

## 📜 Introdução

Seja bem-vindo ao **Nexus Analítico**. Este repositório abriga uma ferramenta poderosa de inteligência de mercado: o `app.py`. Mais do que um simples conjunto de gráficos, este código representa a cristalização de um exemplo dados brutos em conhecimento acionável, permitindo uma exploração profunda e interativa do cenário salarial de funcionários na área de dados.

Este projeto marca um ponto de convergência entre a Ciência de Dados e a Engenharia de Software, demonstrando como transformar arquivos estáticos em experiências visuais dinâmicas, onde o operador não apenas vê, mas interage com a informação.


## ⚙️ Arquitetura, Funcionalidades e Objetivo

O sistema foi arquitetado para oferecer transparência, interatividade e insights imediatos. Suas principais características incluem:

*   **Interface Web Instantânea (`Streamlit`)**: O sistema materializa uma aplicação web robusta diretamente do código Python. Ele converte lógica de script em uma interface visual fluida, eliminando as barreiras entre o processamento de dados e a visualização final.
*   **Motor de Processamento Analítico (`Pandas`)**: O código possui um núcleo matemático capaz de ingerir, limpar e manipular grandes volumes de dados tabulares. Ele calcula métricas vitais — como médias salariais e modas estatísticas — em tempo real.
*   **Visualização Interativa de Alta Fidelidade (`Plotly`)**: Gráficos estáticos são coisa do passado. Aqui, as visualizações respondem ao toque, permitindo zoom, seleção e exploração detalhada de distribuições salariais, proporções de trabalho remoto e mapas geográficos.
*   **Sistema de Filtragem Multidimensional**: O operador detém o poder de segmentar a realidade. Através de uma barra lateral intuitiva, é possível refinar a análise por múltiplos critérios simultâneos: Ano, Nível de Senioridade, Tipo de Contrato e Tamanho da Empresa.


## 💻 Como Executar

Para invocar este dashboard e navegar pelos oceanos de dados, siga os passos rituais abaixo:

1.  Certifique-se de que o **Python 3.x** esteja devidamente instalado em sua máquina.
2.  Instale as dependências sagradas necessárias para a execução do oráculo:

    ```bash
    pip install streamlit pandas plotly
    ```

3.  Abra o seu terminal ou prompt de comando.
4.  Navegue até o diretório deste projeto.
5.  Execute o comando de invocação (note que utilizamos o `streamlit` e não o `python` diretamente):

    ```bash
    streamlit run app.py
    ```

6.  O navegador se abrirá automaticamente, revelando o dashboard em toda a sua glória. Caso não abra, clique no link fornecido no terminal (geralmente `http://localhost:8501`).
