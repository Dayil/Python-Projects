# 🏛️ O Guardião dos Inteiros: Número Informado - Guia Completo

> *Todo sistema inteligente começa ouvindo bem.*

## 📜 Introdução

Seja bem-vindo ao **Conversor Universal**. Este repositório abriga um artefato crucial para a manipulação de dados: o `numeroinformado.py`. Mais do que uma simples solicitação de dados, este código representa a capacidade do sistema de interpretar, validar e transformar a entrada humana em valores numéricos processáveis.

Este exercício avança na minha jornada de documentação de programação, introduzindo conceitos de tipos de dados, conversão (*casting*) e tratamento de erros. É o passo fundamental para garantir que o software lide com números de forma robusta e previsível.


## ⚙️ Arquitetura, Funcionalidades e Objetivo

O algoritmo foi forjado para demonstrar a robustez na captura de dados e suas principais características incluem:

*   **Ciclo de Execução Persistente (`While True`)**: O programa mantém-se em um estado de vigilância constante, recusando-se a encerrar até que um número válido seja fornecido.
*   **Blindagem contra Erros (`Try/Except`)**: O sistema possui um mecanismo de defesa avançado. Caso o operador insira caracteres não numéricos (como letras ou símbolos), o código intercepta o erro e solicita gentilmente uma nova tentativa, evitando o colapso do programa.
*   **Transmutação de Tipos**: O código demonstra a alquimia da programação ao converter texto (`string`) para ponto flutuante (`float`) e, finalmente, cristalizá-lo como um número inteiro (`int`), exibindo o resultado purificado ao usuário.


## 💻 Como Executar

Para executar este programa e testar suas capacidades de conversão, siga os passos abaixo:

1.  Certifique-se de que o **Python 3.x** esteja devidamente instalado em sua máquina.
2.  Abra o seu terminal ou prompt de comando.
3.  Navegue até o diretório deste projeto.
4.  Execute o comando de invocação:

    ```bash
    python numeroinformado.py
    ```

5.  Quando solicitado, digite qualquer número (inteiro ou decimal) e pressione **Enter**. Sinta-se livre para testar a resistência do sistema digitando textos aleatórios.
